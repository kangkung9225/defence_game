# Week 2 개선 제안 — 작동하는 미리보기 (Interactive Web Previews)

공식 개발은 Unity 기준으로 진행하되, **새로운 시스템 · 기믹 · UI 개선 제안은 Unity가 아니어도 누구나 바로 눌러보고 체험할 수 있는 미리보기 형태**로 제안합니다.

## 포함된 미리보기 파일

1. **`01_baseline_stage01_preview.html`**
   - 1차 기획서(#11~#14) 원안 스펙을 그대로 동작하도록 구현한 기준 비교용 시뮬레이션입니다.
   - PC/모바일 브라우저에서 파일을 열면 즉시 실행됩니다.
2. **`02_expanded_v2_1_5_preview.html`**
   - 2.2× 횡스크롤 확장 전장, 광학 마나 및 전면 컷인 스킬, 5분 이중 승리 조건, 전공 포인트 공방 업그레이드, 모바일 가로/세로 반응형 HUD까지 반영한 개선 제안 버전입니다.

## 실행 및 검토 방법
- 로컬에서 `.html` 파일을 더블클릭해 Chrome/Edge 또는 모바일 브라우저에서 바로 플레이하거나, PR 본문의 웹 테스트 링크를 통해 체험합니다.
- PR 댓글로 **"좋았던 점 / 수정하고 싶은 점 / 공식 Unity 편입 찬성 항목"**을 자유롭게 남겨주세요!
