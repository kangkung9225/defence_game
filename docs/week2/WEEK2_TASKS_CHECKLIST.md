## 3. 필요한 UI / UX 화면 및 컴포넌트 에셋 (`Assets/Sprites/UI/`)
*해상도 기준: Android 16:9 가로 모드 (`1920×1080`)*

- [ ] **메인 로비 & 출격 편성 화면:** Stage 01 「황금빛 국경」 출격 선택 화면, 전사·궁수 카드 순서 편성 미리보기 UI, 짧은 도입 문구 연출창
- [ ] **인게임 상단 HUD (상단 약 14%):** 광학 성소 위 아군 HP 바, 증기 요새 위 적군 HP 바, 중앙 스테이지명·경과 시간 표시, 우측 끝 일시정지 버튼
- [ ] **인게임 하단 조작부 (하단 약 22%):** 좌측 재료 및 출력기(`가용 / 총량`) 표시창, 공방 출력기 제작 버튼(60재료·8초 진행 상태 표시), 고정 순서 병종 카드(기본 상태 / 훈련 중 회색 초상화 + 중앙 남은 초 단일 숫자 표시 / 재료·출력기 부족 강조 표시 / 훈련 슬롯 `2/2` 표시), 전장 우측 가장자리 원형 현현 버튼(첫 판 `준비 중` 표시)
- [ ] **일시정지 & 결과창 팝업:** 일시정지 창(`계속` / `메인으로` 중도 종료 확인창), 결과창(`승리`·`패배`·`동시 파괴 무승부` / 파괴된 요새 및 경과 시간 표시 / `재도전`·`메인으로` 버튼)
