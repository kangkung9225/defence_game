## 1. 자원(광학 재료 · 출력기) 및 공방 순환 시스템 (`Assets/Scripts/Core/`)
- [ ] **광학 재료 충전:** 시작 재료 `150`, 전투 중 초당 `+5` 자동 누적 및 실시간 HUD 표시
- [ ] **출력기 상태 관리 (`가용 → 훈련 예약 → 장착 → 사망 후 회수 대기 → 가용`):** 시작 출력기 `10개`, HUD에 항상 `가용 / 총량` 표시
- [ ] **사망 후 5초 출력기 회수:** 아군 병사 사망 시 장착 출력기(전사 1개, 궁수 2개)를 `5초` 회수 대기열에 넣고, 완료 시 가용 수 복귀 및 회수 알림음 호출
- [ ] **공방 출력기 제작:** 재료 `60` 차감 · 공방 슬롯 1칸 점유 · `8초` 타이머 작동 후 총량과 가용 수 각각 `+1` 증가 (병사 훈련과 동시 가동 가능)

## 2. 병종 훈련 입력 판정 & 2/2 슬롯 큐 (`Assets/Scripts/Core/`)
- [ ] **훈련 입력 조건 회로 (기획안 플로우차트 기준):** `전투 진행 중` → `재료 충분` → `같은 병종 훈련 중 아님` → `빈 훈련 슬롯(2/2 미만)` → `가용 출력기 충분` 순서로 판정
- [ ] **중복 차감 방지 및 부족 피드백:** 훈련 중인 같은 카드를 연타해도 진행 중인 초 숫자를 유지하고 추가 비용 차감 차단 / 재료·출력기·슬롯 부족 시 부족 사유 시각 피드백 표시
- [ ] **출전 및 실패 롤백:** 훈련 시간(전사 4초, 궁수 6초) 경과 후 아군 성소 앞에 유닛 스폰 및 슬롯 반환 (스폰 실패 시 재료·예약 출력기·슬롯 복구)
