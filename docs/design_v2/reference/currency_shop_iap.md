## 4. 가챠(파편) & 천장
- 등급 확률 = 유닛 등급 분포 **2.3 / 13.6 / 68.2 / 13.6 / 2.3%** (병맛 포함)
- **천장(pity)**: 40뽑 내 ≥영웅 1회, 100뽑 내 전설 1회 보장
- 중복 → 파편 분해(등급별 30/80/120/200)
- 병맛(하위 2.3%)은 **코믹 도감** 용도 + 분해 보상

## 7. 수익화 밸런스 & 윤리
- **광고는 선택**(강제 삽입 없음): 일일 한도, 버프/충전용.
- **천장/확률 공개**(등급 확률·pity 명시).
- **과금 상한 표시**(月 결제 한도 안내), 미성년자 보호.
- F2P도 전 콘텐츠 도달 가능(시간 소요). P2W는 성장 속도 차이로 제한.
