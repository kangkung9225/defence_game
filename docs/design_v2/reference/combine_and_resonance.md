# v2 재사용 수치 — 유닛 결합(합성) 규칙: 가중 공명(Resonance) 모델

> 작성일: 2026-11-15 · 상태: **v2 재사용 확정(가중 공명 + 시뮬레이션 튜닝)** · 기획 파트
> 관련: [특성 상세](./trait_details.md) · [v2 정본](../design/master_design_v2.md)
> 원칙: 결합 효과는 **고정 매트릭스가 아니라, 두 유닛의 상징 특성(도덕·연령·충동·공감·사교 등)을 공명축에 가중 합산**해 창발적으로 결정. 기본 특성은 **유지 + 효과 추가**. 민감 표현은 동조/교차로 은유.

## 2. 결합 = **가중 공명(Resonance)**

결합 시 두 유닛의 특성들을 **7개 공명축**에 가중 합산 → 점수가 가장 높은 축(지배축)이 결합 효과를 결정, 2위 축(부축)이 보정, 특정 조합이면 특수 변이.

| 공명축 | 의미 | 대표 유도 특성 |
|---|---|---|
| **A 공격** | 화력·연격 | 충동(열정), 이기, 신체, 패기 |
| **D 수비** | 맷집·요새 | 강골, 거구, 성인 |
| **S 지원** | 힐·버프 | 공감(다정), 이타 |
| **P 생산** | 인구 증가 | 친화(사교), 아이 |
| **W 지혜** | 잠재·계승 | 지능(총명), 연륜(노인), 잠재, 불굴 |
| **C 혼돈** | 변이·도박 | 충동, 이기, 취약, 병약 |

> **결속(동조)**: 같은 진영 결합은 축 경쟁과 무관하게 **항상 더블어택 오버레이**로 추가(§4-3).

### 2-1. 특성 → 공명축 가중치 (단위 유닛)

**🔥 불꽃**
| 특성 | 축 |
|---|---|
| 강골 | D2 |
| 총명 | A1 W1 |
| 열정 | A1 C1 |
| 냉철 | A1 W1 |
| 이기 | A1 C1 |
| 이타 | S2 |
| 불굴 | A1 W1 |
| 협소 | A1 C1 |
| 거구 | D2 |
| 신속 | A1 |
| 취약 | C2 D−1 |
| 재생 | D1 S1 |

**🌱 새싹**
| 특성 | 축 |
|---|---|
| 다정 | S2 |
| 친화 | P3 |
| 총명 | A1 W1 |
| 강골 | D2 |
| 열정 | A1 C1 |
| 고독 | A1 W1 |
| 이타 | S2 |
| 이기 | A1 C1 |
| 연륜 | W2 |
| 패기 | A2 |
| 병약 | C2 D−1 |
| 잠재 | A1 W1 |

**연령 오버레이** → 축: 아이 `P2 W1` / 청년 `A1` / 성인 `D1` / 노인 `W2`

**도덕 명시 가중**(요청 반영): 선 `S+1 P+2` / 악 `A+1 C+1` / 중립 0

> P축 보강(v2): 친화 `P2→P3`, 아이 `P1→P2`, 선 `P1→P2`. (P 비중 3~8% → 22~56%로 상향)

**진영(결속)**: 같은 진영 결합 시 §4-3의 **더블어택을 항상 추가**(축 경쟁과 무관한 오버레이). 다른 진영은 없음.

## 3. 공명 점수 계산

```
각 유닛의 축점수 = Σ(보유 특성 가중) + 연령 가중 + 도덕 명시 가중
결합 축점수 R_k = R_k(A) + R_k(B)            (k = A,D,S,P,W,C)
정규화 점수 = R_k × c_k                       # c_k = 축 균형 계수(아래)
지배축 = argmax(R_k × c_k)   /   부축 = 2nd
```

### 3-1. 축 균형 계수 c_k (시뮬레이션 튜닝 v2, 확정)
| 축 | A | D | S | P | W | C |
|---|:--:|:--:|:--:|:--:|:--:|:--:|
| **c_k** | 0.18 | 0.26 | 0.24 | 0.30 | 0.24 | 0.24 |

> 계수만 조정해도 창발 패턴 전체가 바뀜 → 밸런스 손잡이. (아래 §4-4 검증 결과)

## 4. 결합 효과 (지배축 기반, 크기는 점수에 비례)

### 4-1. 기본 특성은 유지 (대체 아님)
- 결과 특성 = **A특성 ∪ B특성** (양쪽 보존, 중복 보정 ×1.5)
- 기본 스탯 = 통합 특성으로 기존 공식 재계산

### 4-2. 지배축 → 추가 효과 (기본 위에 얹음)
| 지배축 | 추가 효과 (크기 ∝ R) | 창발 예 |
|---|---|---|
| **A 공격** | ATK/공속 ×(1 + 0.06·R_A), 연격 | 폭딜·연격형 |
| **D 수비** | HP ×(1 + 0.08·R_D) | 요새·탱커형 |
| **S 지원** | 힐·아군버프, 인구 +(0.05·R_S)%/초 | 흡수·지원형 |
| **P 생산** | 인구 +(0.08·R_P)%/초 | 생산 폭발형 |
| **W 지혜** | 잠재 성장 ×(1 + 0.05·R_W) 누적 | 계승·각성형 |
| **C 혼돈** | **변이 도박**: 성공확률 `clamp(0.05·R_C, 5%, 50%)` → 성공 ×2.0 / 실패 소멸 | 초강력↔소멸 |

### 4-3. 결속 오버레이 (같은 진영)
- **같은 진영 결합은 항상 `더블어택(2연타)` 추가** (지배축 효과와 **별개로** 얹힘).
- (요청: 동조 결합 → 더블어택. 축 경쟁 없이 확정 효과로 보장)

### 4-4. 시뮬레이션 검증 결과 (60k 쌍, c_k v2 + P 보강)
| 시나리오 | 지배축 분포(요약) |
|---|---|
| 랜덤 | **A34 / D11 / S10 / P22 / W10 / C13** (전 축 고루 분포) |
| 악+악 | A53 / **C36** (변이 도박 다수, 성공률≈44%) |
| 선+선 | **P56 / S30** (생산·지원 공명) |
| 악+선 | A40 / P24 / C17 / W8 (공격·생산 하이브리드) |
| 노인+아이 | **W40 / P28** (계승 각성) |
| 동조(같은 진영) | 더블어택 **100%** (오버레이) |
- **P 보강 완료**: 생산축이 랜덤 22%·선+선 56%로 정상화. 모든 축이 랜덤에서 10% 이상 확보.

- **부축**: 지배축의 50% 크기로 보너스 추가(복합 성향 창발).
- **특수 상호작용**: `A높음 & C높음`=광폭 변이(도박 강화), `S높음 & P높음`=생산 공명(인구 대폭), `W높음 & 연령(노인+아이)`=계승 각성.

> 즉 "악+선→흡수", "악+악→도박", "선+선→생산", "동조→더블", "노인+아이→계승"은 **하드코딩이 아니라 가중치에서 창발**됨.

## 5. 최종 스탯 공식

```
1) 특성통합 = A특성 ∪ B특성
2) 기본      = 트레이트 공식(특성통합)
3) R_k 계산  = 두 유닛 축점수 합 (도덕/연령/진영 포함)
4) 최종      = 기본 × (지배축 배율) × (부축 0.5 보정) + 지배축 가산
```
- 결과 등급: 통합 특성 P로 백분위 재산정.
- 모든 계수(0.06/0.08/0.05/배율)는 1차 초안·튜닝 대상.

## 6. 창발 예시 (가중 계산으로 도출)

**예 A — 불꽃 악 + 새싹 선**
- A(악): 강골·이기·열정·거구, 청년 → A4 D4 C3
- B(선): 다정·이타·친화·연륜, 노인 → S5 P3 W4
- R: **S5** > A4=D4=W4 > C3, B0 → 지배=지원, 부축=공격/수비/지혜(복합)
- 결과: **지원 공명 + 공격 흡수 하이브리드** (힐/일부 인구 + 화력 보정) → 단순 "악이 흡수"보다 입체적

**예 B — 불꽃 악 + 불꽃 악 (동조)**
- 둘 다 이기·열정 → 각 A3 C3, 같은 진영 B3
- R: **A6 = C6**, B3 → 공격·혼돈 동률 → **광폭 변이 + 결속 연격**
- 결과: 변이 도박(성공확률 ∝ R_C) + 2연타 → 고위험 고화력

**예 C — 새싹 선 + 불꽃 선**
- 다정·이타·친화(S/P) 다수 → **S·P 지배** → 생산 공명(인구 대폭) + 힐

**예 D — 노인 + 아이**
- 노인 W2 + 아이 W1 P1, 연령 가중 누적 → **W 지배** → 계승 각성

**예 E — 불꽃 + 불꽃 (동조)**
- B3 + 공격/수비 → 결속이 상위면 **더블어택**

## 7. 결합 위치 / 규칙

- **기본: 로비/덱 합성** (구현 단순). **확장: 전장 인접 합성**(2주차 이후 옵션).
- 결합 시 두 유닛 소모(혼돈 실패는 둘 다 소멸). 결과 1개.

---

## 8. 민감 표현 처리

- "동성/이성" 대신 **동조(같은 진영)/교차(다른 진영)**.
- 실제 정체성 라벨 비노출. 결합 로직은 **상징 특성·공명축** 기반.
- 목표 연령등급 유지(전연령~12세).

---

## 9. 밸런스 고려

- **결합은 항상 이득(유지+추가)** → 결합 비용/횟수/등급 재산정으로 남용 방지.
- **혼돈(C) 도박**: 성공확률이 R_C에 비례 → 악·충동 스택이 강할수록 도박성↑. 상한 50% 필요.
- **생산(S/P) 공명**: 인구 폭증 방지 상한/쿨다운.
- **결속(B) 더블어택**: 동조만 노리는 편중 방지(다른 축 매력과 균형).
- 공명 가중치 행렬(특성×축)만 만지면 **전체 창발 패턴을 한 번에 튜닝** 가능.
