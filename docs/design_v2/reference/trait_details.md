| 공격력(ATK) | 25 | 16 |

- 보정은 **합연산**(같은 항목 %끼리 더함). 동시 소환 상한 **12기**.

## 3. 등급 컷 (진영별 z 기준, P = μ + z·σ)

| 등급 | 조건(z) | 불꽃 P | 새싹 P | 비율 |
|---|---|--:|--:|:--:|
| **전설** | z ≥ 2 | ≥ 4.04 | ≥ 4.54 | ~2.3% |
| 영웅 | 1 ≤ z < 2 | 2.90–4.04 | 3.40–4.54 | ~13.6% |
| 일반 | −1 ≤ z < 1 | 0.60–2.90 | 1.10–3.40 | ~68% |
| 하급 | −2 ≤ z < −1 | −0.54–0.60 | −0.04–1.10 | ~13.6% |
| **병맛(함정)** | z < −2 | < −0.54 | < −0.04 | ~2.3% |

- P 범위: 불꽃 [−1.5, 5.0] / 새싹 [−1.0, 5.5]

### 3-1. 시뮬레이션 검증 결과 (2026-11-13, 전수 4,096 + 몬테카를로 50만) ⚠️

- **이론/전수 일치**: 평균·표준편차가 이론값과 정확히 일치 (불꽃 μ1.750 σ1.146 / 새싹 μ2.250 σ1.146).
- **몬테카를로(50만) vs 전수**: 모든 등급 비율 차이 < 0.1% → 생성기 로직 정상. ✅

**BUT 실제 등급 비율이 가정(정규분포 2.3/13.6/68.3/13.6/2.3%)과 다름:**

| 등급 | 전수(정확) | 몬테(50만) | 가정값 |
|---|:--:|:--:|:--:|
| 전설 | 48 (**1.17%**) | 1.17% | 2.3% |
| 영웅 | 760 (**18.55%**) | 18.59% | 13.6% |
| 일반 | 2480 (**60.55%**) | 60.57% | 68.3% |
| 하급 | 760 (**18.55%**) | 18.51% | 13.6% |
| 병맛 | 48 (**1.17%**) | 1.15% | 2.3% |

**원인**
1. **이산 분포**: 가중치가 0.5 단위라 P값이 뚝뚝 끊겨 정규분포에 완전히 안 붙음.
2. **완전 대칭**: 각 조합의 여집합이 `P' = Σw − P` → 분포가 μ 기준 대칭 → **전설 수 = 병맛 수** 정확히 같음.

**z 임계별 상위 비율(불꽃, 전수)**: z≥2.0 →1.17% / z≥1.6 →3.91% / z≥1.1 →9.77% / z≥1.0 →19.73%
→ 2.3% 같은 **매끄러운 컷이 안 나옴**(뚝뚝 끊김).

**수정 권장(택1)**
- **(권장) 백분위 기반 등급**: P 순위로 **상위 2.3%=전설 / 하위 2.3%=병맛** 등 컷 → 분포 모양과 무관하게 목표 비율 정확히 확보.
- **특성 수↑(n≈16)+가중치 세분화(±0.25)**: 분포가 연속에 가까워져 자연스러운 2.3% 가능.
- **비대칭화**: 음수 가중치 완화(예: 취약 −1.0→−0.5)로 병맛을 전설보다 적게.

## 4. 샘플 롤 (계산 검증)

**① 불꽃 · 강골+총명+열정+불굴** (w=3.0)
- HP 150×1.15 = **173** / ATK 20×1.30×0.85 = **22**(성장) / 간격 1/1.3 = **0.77초** / 사거리 3.5
- P=3.0 → z=1.09 → **영웅** / 코스트 71 / 쿨 3.8초

**② 불꽃 · 강골+거구+재생+취약** (w=1.0)
- HP 150×(1+0.3+0.5−0.3)=**225** / ATK **20** / 이동 −30% / HP 3%/s 재생
- P=1.0 → z=−0.65 → **일반** / 코스트 47 / 쿨 2.6초 — *단단한 탱커*

**③ 새싹 · 다정+친화+잠재** (w=3.0)
- HP 150×1.10=**165** / ATK 20×1.0×0.85=**17**(성장) / 힐 +30% / **인구 +0.4%/s**
- P=3.0 → z=0.65 → **일반** / 코스트 71 / 쿨 3.8초 — *전투력은 평범, 전략 가치(인구) 높음*

**④ 불꽃 · 취약+협소+열정+신속** (w=−1.5)
- HP 150×(1−0.30−0.15−0.10)=**68** / ATK 20 / 간격 1/1.5=0.67 / 이동 +40%
- P=−1.5 → z=−2.84 → **병맛(함정)** / 코스트 20 / 쿨 1.5초 — *대환장 유닛*

## 5. 가챠 확률 — **확정: 백분위(percentile) + 동점 분할**

- 실측에서 z컷은 1.17%/3.91%/9.77%로 뚝뚝 끊김 → **순위(백분위) 방식 채택(확정)**.
- 목표 비율: **전설 2.3% / 영웅 13.6% / 일반 68.2% / 하급 13.6% / 병맛 2.3%**
  - 4,096종 기준 **94 / 557 / 2,794 / 557 / 94** (합 4,096).
- **동점(P 동일) 처리**: 경계 P의 동점군은 **확률 분할**(같은 P라도 목표 비율을 맞추기 위해 상위/하위 등급에 확률적으로 배정). → 같은 P 유닛이 경계에서만 소수 갈림(공정성은 랜덤으로 확보).

### 5-1. 확정 컷오프 (전수 계산 결과)

**🔥 불꽃 진영**
| 등급 | P 컷오프 | 동점 분할 |
|---|---|---|
| 전설 | P > 4.0 | P=4.0의 **41.1%** → 전설(나머지 영웅) |
| 영웅 | 3.0 < P ≤ 4.0 | P=3.0의 **77.7%** → 영웅(나머지 일반) |
| 일반 | 0.5 < P ≤ 3.0 | P=0.5의 **77.0%** → 일반(나머지 하급) |
| 하급 | −0.5 < P ≤ 0.5 | (일반/병맛 경계가 P=±0.5, 대칭) |
| 병맛 | P ≤ −0.5 | P=−0.5의 **41.1%** → 병맛(나머지 하급) |

**🌱 새싹 진영** — 동일하되 **+0.5 시프트**(μ 차이)
| 등급 | P 컷오프 |
|---|---|
| 전설 | P > 4.5 (P=4.5의 41.1%) |
| 영웅 | 3.5 < P ≤ 4.5 (P=3.5의 77.7%) |
| 일반 | 1.0 < P ≤ 3.5 (P=1.0의 77.0%) |
| 하급 | 0.0 < P ≤ 1.0 |
| 병맛 | P ≤ 0.0 (P=0.0의 41.1%) |

- **구현 권장**: 게임 시작 시 4,096개 P를 정렬해 두고, 유닛 P의 **순위 백분위**로 등급 산정(동점은 랜덤 분할). 또는 위 컷오프·분할값을 상수로 하드코딩.
- **대칭 성질**: 전설 수 = 병맛 수(동일). 병맛을 더 줄이려면 음수 가중치 완화(§6).
- 천장(pity): N회 내 전설 1회 보장. 전설 상한 옵션으로 파워 크리프 방지.

## 6. 밸런스 주의

- **지원형 등급 왜곡**: '친화(인구)' 같은 전략 가치는 P(전투력)에 일부만 반영 → 지원형이 등급상 낮게 보일 수 있음. 필요 시 **전략 코스트 보정**(인구형 유닛 코스트 상향)으로 조정.
- **Σw / Σw²**만 만지면 분포가 바뀜 → 진영별 평균·표준편차를 원하는 대로 튜닝 가능.
- 수치는 **v2 재사용 확정안**이며 **플레이테스트 후 가중치(w) 미세조정** 전제.
