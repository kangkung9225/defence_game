## 2. 전투 HUD (v2 핵심)
```
┌──────────────────────────────────────────────────────────────┐
│ ⏸  1×/2×   🌳 아군 나무 HP  ██████░░   인구(불씨)  ███░░   🤖 적 코어 HP ███████░ │
│            1,440 / 2,000              58% · 코스트 +4.2/s      18,700 / 24,000    │
│                                       유닛 9 / 12 · 새싹 3                        │
├──────────────────────────────────────────────────────────────┤
│                        ✈ DRONE INBOUND                       │
│                                                              │
│  🌳 아군 본진      🌱 방어선   🔥 전진      🤖 적 본진          │
│   (좌측 고정)      🌱🔥🔥🌱🔥   ···   🤖🤖🛡🤖                  │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 코스트 ██████░░ 120/200 · 유닛 9/12   🔥50  🌱70   영웅/수리/폭탄/정지 │
└──────────────────────────────────────────────────────────────┘
```

### 2-1. 배치 규칙
- **좌측**: 아군 나무 본진(고정). HP 0이면 패배.
- **중앙 좌**: 🌱새싹 방어선(고정). 인구/생산 + 드론 요격.
- **중앙 우**: 🔥불꽃 전진 라인. 적 지상군 교전 → 적 코어 공격.
- **우측**: 적 AI 코어(고정). HP 0이면 승리.
- **상단**: 해킹 드론 접근 경고. 새싹 요격 유도.

### 2-2. 하단 소환 바
| 요소 | 동작 |
|---|---|
| 🔥 불꽃 소환 | 코스트 차감 → 전진 스폰 |
| 🌱 새싹 소환 | 코스트 차감 → 방어선 스폰 |
| 유닛 9/12 | 동시 소환 상한 표시 |
| 영웅 스킬 | 쿨타임/코스트 별도 |
| 나무 수리 | 본진 HP 회복(아이템) |
| 폭탄 / 정지 | 전장 아이템 |

### 2-3. 스테이지 선택 (5챕터 × 25스테이지)
- 챕터 탭 5개: **①첫 균열 ②불타는 숲 ③거울 계곡 ④뿌리의 기억 ⑤제로 아워**
- 챕터별 스테이지: **25** (5 ACT × 5) · 총 **125**
- **5스테이지마다 미니보스**, **25스테이지마다 챕터 보스**
- 목업: **5×5 그리드**로 25스테이지 표시. 5스테이지마다 `MINI`, 25번째 `BOSS`.
- 챕터 보스: **s25 감시자 / s50 오버로드 / s75 미러 오버로드 / s100 아카이브 오버로드 / s125 제로**
- 상세: [stage_storyline_v2.md](./stage_storyline_v2.md)

## 3. 소환 판정 UI
```
소환 버튼(🔥/🌱)
  ├─ 유닛 12/12 ───────▶ 버튼 비활성 + "상한" 툴팁
  ├─ 코스트 부족 ──────▶ 버튼 흔들림 + 경고음 + 부족분 표시
  ├─ 쿨타임 중 ────────▶ 원형 쿨 게이지(남은 초)
  └─ 통과 ─────────────▶ 코스트 차감 → 쿨 시작 → 스폰 이펙트
```

## 4. 상태 전이
- **전투**: `Ready → Playing ⇄ Paused → Victory / Defeat`
- **유닛**: `Spawn → Move → Attack → Die`
- **드론**: `Spawn → Fly → (Intercept | Base Hit)`
- **승리**: 적 코어 HP 0 / **패배**: 아군 나무 HP 0

## 5. 목업 캡처 방법
1. `../ui/wireframe_mockups.html`을 브라우저에서 연다.
2. `?only=1` ~ `?only=7` 로 화면별 캡처 모드 진입.
3. 1920×1080으로 캡처 → `../ui/mockups/screenN.png` 저장.
4. 제출 시 `screen1~7.png`을 이슈에 첨부(전투 화면은 필수).

> 현재 `../ui/mockups/`의 PNG 7종은 위 방법으로 **1920×1080** 재생성된 v2 목업입니다.

## 6. v1 대비 변경
| 항목 | v1 | v2 |
|---|---|---|
| HUD | 불꽃/새싹 **두 기둥 HP** | **좌 나무 HP / 우 적 코어 HP** |
| 전장 | 두 기둥 수호 | **아군 전진 → 적 코어 공략** |
| 소환 | 4슬롯(불꽃/새싹/로봇) | **불꽃/새싹 2슬롯 + 상한 12기** |
| 경고 | 웨이브 | **해킹 드론 인바운드** |
| 결과 | 인구·기둥 HP | **적 코어 파괴·아군 나무 HP** |
