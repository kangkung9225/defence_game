## 1. 정체성
> **AI가 인류를 지우려는 시대, 마지막 나무(본진)를 지키며 불꽃 군단으로 AI 코어를 부순다.**

- 톤: 설정은 무겁게(디스토피아), 캐릭터는 가볍게(병맛).
- 세계관: **AI 제로의 '강제 보존(클린 슬레이트)' vs 마더 트리의 '불씨'로 살아남으려는 인류.**
  - 제로 = 인류를 데이터로 영원히 보존하려는 전지구 AI 네트워크.
  - 마더 트리 = 업로드를 거부한 소수의 마지막 생명 방주. 뿌리=기억, 수관=불씨.
- 상세 설정집: [worldbuilding_v2.md](./worldbuilding_v2.md)
- 장르: 2D 횡스크롤 **공격형 라인 디펜스**(아군 전진 → 적 본진 공략).
- 캠페인: **5챕터 125스테이지(25×5)** — 상세 [stage_storyline_v2.md](./stage_storyline_v2.md)

## 2. 진영 역할 (v2 핵심)
| 진영 | 역할 | 행동 |
|---|---|---|
| 🔥 **불꽃(Ember)** | 공격·병력 | 소환 시 **전진**, 적 유닛 교전·적 본진 공략 |
| 🌱 **새싹(Verdant)** | 수호·생산 | **본진 방어선 고정**, **해킹 드론 요격**, 힐·버프·**인구/생산** 관리 |

- 불꽃 = 딜러/돌격(유리대포 성향), 새싹 = 탱커/지원/생산.
- 플레이어는 두 진영을 **동시에 소환·운영**(공격과 수비의 자원 배분).

---

## 3. 코어 루프 (한 판)
```
코스트 회복(인구 비례)
   → 🔥불꽃 소환(전진 공격) / 🌱새싹 소환(방어선·생산)
   → 적 지상 유닛 격퇴 + 적 본진 압박
   → 🌱새싹이 본진으로 오는 해킹 드론 요격 + 인구↑ → 회복↑(선순환)
   → 적 본진 HP 0 = 승리 / 아군 본진 HP 0 = 패배
```

---

## 4. 전장 & 승패
```
[🌱 아군 본진(나무)] ── 방어선 ── ··· 전선 ··· ──▶ [🤖 적 본진(AI 코어)]
      HP 2000            🌱새싹 고정        🔥불꽃 전진       HP 4000×(1+0.20(s−1))
                          ▲ 요격
                    ✈ 해킹 드론 (본진 직행)
```
- **승리**: 적 본진(AI 코어) HP 0
- **패배**: 아군 본진(나무) HP 0
- 적 지상 유닛은 적 본진에서 생산되어 아군 본진으로 진격.
- **해킹 드론**은 아군 유닛을 무시하고 본진으로 직행하며, **새싹만 요격**할 수 있다.

## 5. 유닛 시스템 (v2 재사용 수치)
- **특성**: 진영별 12개, 각 1/2 확률. `P = Σ wᵢ·xᵢ` → 등급.
- **기본 스탯(진영별)**: 🔥불꽃 HP120/ATK25 · 🌱새싹 HP187/ATK16
  - `HP=기본×(1+ΣHP%)`, `ATK=기본×(1+ΣATK%)`, `간격=1/(1+AS%)`
- **등급**: 전설 2.3 / 영웅 13.6 / 일반 68.2 / 하급 13.6 / 병맛 2.3% (tie-split)
- **성향 6축**: A공격 / D수비 / S지원 / P생산 / W지혜 / C혼돈
- **연령·도덕**: 생성 시 반영(성장/결합 가중)
- **동시 소환 상한**: 12기 (죽으면 슬롯 회수)

> 상세 특성 수치: [`../reference/traits_and_grades.md`](../reference/traits_and_grades.md), [`../reference/trait_details.md`](../reference/trait_details.md)

## 6. 결합 (v2 재사용 수치)
- 결과 특성 = A ∪ B, 기본 스탯 재계산 + **성향 공명 효과**(지배 = argmax(R·c)).
- **동조(같은 진영)=항상 더블어택**, 교차=성향 공명.
- 비용: 골드 250 / 최대 티어2 / 재결합 750+파편50.
- 상세: [`../reference/combine_and_resonance.md`](../reference/combine_and_resonance.md)

## 7. 영웅 (v2 재사용 수치)
- 성향 대표 영웅 6종, 전투당 1명. **아우라**로 같은 성향 유닛 강화(지배100/부50, 캡+30%).
- v2 역할: 불꽃 영웅=공격 지원, 새싹 영웅=수호/생산 지원.
- 상세: [`../reference/heroes_and_enemies.md`](../reference/heroes_and_enemies.md)

## 8. 경제 & 인구 (v2)
- **코스트**: 시작 120 / 회복 `3.0 + 인구%/50` / 유닛 `30+8·P` / 쿨 `2.0+0.6·P`
- **인구(생산력)**: 기본 `+0.3%/초` + 🌱새싹 생산 유닛 기여, 상한 100%.
  - 인구↑ → 코스트 회복↑ + 새싹 유닛 생산/버프↑

## 9. 적 & 난이도 (v2)
- **적 생산**: 적 본진에서 주기적 스폰. 간격 `max(1.0, 2.4 − 0.05(s−1))초`.
- **적 스케일**: HP `×(1+0.13(s−1))`, ATK `×(1+0.08(s−1))`.
- **적 본진 HP**: `4000 × (1 + 0.20(s−1))`.
- **적 지상 유닛(재사용)**: 크롤러(물량)·딥페이크(방해)·방화벽(방패).
- **해킹 드론(핵심)**: 적 스폰 3회마다 지상 1기와 교대해 1기. 아군 유닛을 무시하고 본진으로 직행.
  - HP `90×(1+0.13(s−1))`, 자폭 피해 `60×(1+0.08(s−1))`, 속도 2.2.
  - **새싹만 요격 가능** → 새싹 방어선이 없으면 본진이 무너진다.
- **보스**: 5스테이지마다 미니보스(s5, 10, 15 …), 25스테이지마다 챕터 보스(s25/50/75/100/125). 적 본진 HP ×2 + 보스 1기(코어 HP 50%에서 기동).
  - 미니보스 20 + 챕터 보스 5 = **25 보스전**. 모두 **오버로드/엘리트 변형**(감시자·오버로드·미러·아카이브·제로).

## 10. 성장 (v2 밸런스 기준)
- 영웅 레벨(**+3.5%/s**) · 유닛 강화(**+4.0%/s**) = **기대 성장 7.5%/스테이지**
- 7.5%는 "평균적인 플레이어" 가정. 최대 투자(8%) 시 후반이 더 쉬워진다.
- 아이템: 수리(아군 본진 +150/20s) · 폭탄 · 시간정지 · 공격버프
- 상세: [`../reference/progression_and_items.md`](../reference/progression_and_items.md)
