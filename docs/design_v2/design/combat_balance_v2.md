## 1. 전장 모델 (1D 라인)
```
x=0                 x=2.5              x=8               x=14
[🌱아군 본진] ── [새싹 방어선] ── (전선) ──▶ [🔥불꽃 전진] ── [🤖적 본진]
   HP 2000           새싹 고정                          적 지상 유닛 스폰
                        ▲
                  ✈ 해킹 드론 (본진 직행, 새싹만 요격)
```
- **아군 본진(나무)**: x=0, HP 2000. HP 0이면 패배.
- **새싹(Verdant)**: x≈2.5 고정. 인구/생산 기여 + **해킹 드론 요격**.
- **불꽃(Ember)**: x=1.5에서 스폰 후 +x 전진. 적 유닛 교전 → 적 본진 공격.
- **적 지상 유닛**: 적 본진(x=12.5)에서 스폰 후 −x 진격. 아군 유닛 → 본진 공격.
- **해킹 드론**: 적 본진에서 스폰해 아군 유닛을 무시하고 본진으로 직행. **새싹만 요격 가능**.

## 2. 승패
| 조건 | 결과 |
|---|---|
| 적 본진 HP 0 | **승리** |
| 아군 본진 HP 0 | **패배** |

## 3. 핵심 전투 규칙
| 규칙 | 값/동작 |
|---|---|
| 동시 소환 상한 | **12기** (죽으면 슬롯 회수) |
| 소환 쿨타임 | `2.0 + 0.6·P` 초 |
| 새싹 타겟팅 | 사거리 내 **드론 우선**, 없으면 지상 적 |
| 불꽃 타겟팅 | 사거리 내 지상 적 → 없으면 전진 → 본진 공격 |
| 드론 스폰 | **적 스폰 3회마다 1기** (지상 1기와 교대) |
| 드론 요격 | 새싹만 가능. 놓치면 본진에 자폭 피해 |

- 상한 12기가 **눈덩이(데스볼)를 방지**하고, 공격/수비 소환 비율을 계속 선택하게 만듭니다.
- 드론이 **본진을 직접 위협**하므로 새싹 방어선이 항상 의미를 가집니다.

## 4. 확정 수치
| 항목 | 값 |
|---|---|
| 아군 본진 HP | **2000** |
| 적 본진 HP | `4000 × (1 + 0.20(s−1))` |
| 적 지상 스폰 간격 | `max(1.0, 2.4 − 0.05(s−1))` 초 |
| 적 지상 HP | `120 × (1 + 0.13(s−1))` |
| 적 지상 ATK | `10 × (1 + 0.08(s−1))` |
| 해킹 드론 HP | `90 × (1 + 0.13(s−1))` |
| 해킹 드론 피해 | `60 × (1 + 0.08(s−1))` (본진 자폭) |
| 해킹 드론 속도 | 2.2 (전진 1.5보다 빠름) |
| 코스트 | 시작 **120** / 회복 `3.0 + 인구%/50` / 유닛 `30+8·P` |
| 인구 | 기본 `+0.3%/s` + 새싹 `+0.1%/s·기`, 상한 100% |
| 기대 성장 | **7.5%/스테이지** (영웅 +3.5% · 유닛 +4.0%) |
| 동시 유닛 상한 | **12기** |

- 적 지상 기본: 크롤러 120/10, 딥페이크 150/12, 방화벽 500/20.
- 보스 스테이지: **5스테이지마다 미니보스, 25스테이지마다 챕터 보스** (s25/50/75/100/125) — 적 본진 HP ×2 + 보스 1기(코어 HP 50%에서 기동).

> 아래 수치는 **24스테이지 시뮬(Chapter 1 일반 구간) 기준**입니다. s25 챕터 보스와 Chapter 2~5는 **§11 챕터 스케일**로 별도 산정합니다.

> 시뮬레이터는 영웅(+3.5%)·유닛(+4.0%) 성장을 **평균 7.5% 단일 배율**로 근사합니다.

### 5-1. 검증 범위
- **포함**: 유닛 생성(특성·연령), 전진/교전, 본진 HP, 드론 요격, 인구/코스트, 성장 7.5%.
- **제외**: 새싹 힐/버프, 결합, 영웅 아우라, 아이템, 보스 패턴.
- **영웅**: 불꽃(공격형) 1명 기준. 새싹 영웅·아이템은 구현 후 재검증.

## 8. 튜닝 가이드
| 목표 | 조정 |
|---|---|
| 전체적으로 어렵게 | 기대 성장 `−0.5%p` (7.5 → 7.0%) |
| 전체적으로 쉽게 | 기대 성장 `+0.5%p` (7.5 → 8.0%) |
| 후반만 어렵게 | 적 HP 계수 `+0.005` (0.130 → 0.135) |
| 드론 압박 강화 | 드론 주기 `3 → 2.5` 또는 피해 `60 → 75` |
| 전투 길게 | 적 본진 HP 계수 `+0.02` |

> 주의: h를 0.001 단위로 미세 조정하면 결과가 비단조적으로 흔들립니다(카오스 + 표본 오차).
> **성장률(0.5%p 단위)** 로 큰 난이도를 잡고, 드론 주기로 방어 압박을 조절하는 것을 권장합니다.

### 11-2. 설계 전제
- 챕터 내부는 완만한 상승(약 +1.5~2%/스테이지), 챕터 경계에서 **성장 티어 해금**으로 점프.

- Chapter 2~5는 **챕터별 성장 티어**(영웅 레벨 캡·유닛 강화·아이템 해금)로 따라잡는 구조.
